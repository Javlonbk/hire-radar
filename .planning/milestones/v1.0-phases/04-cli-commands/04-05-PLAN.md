Refactor `src/cli/auth.ts` to isolate the interactive login behind a seam:

```typescript
import { Command } from 'commander';
import { loadConfig } from '../config.js';

export type LoginFn = (creds: { apiId: number; apiHash: string }) => Promise<string>;

export interface AuthDeps {
  apiId?: number;
  apiHash?: string;
  login: LoginFn;             // injected; default does the real gramjs interactive login
  out: (line: string) => void;
}

export async function runAuth(deps: AuthDeps): Promise<void> {
  if (!deps.apiId || !deps.apiHash) {
    throw new Error('Missing TELEGRAM_API_ID / TELEGRAM_API_HASH — set them in your .env before running auth');
  }
  const session = await deps.login({ apiId: deps.apiId, apiHash: deps.apiHash });
  deps.out('');
  deps.out('Telegram session created. Store this as TELEGRAM_SESSION in your .env:');
  deps.out('');
  deps.out(session);
  deps.out('');
  deps.out('WARNING: this is a long-lived credential — never commit it. ingest reads it from TELEGRAM_SESSION.');
}
```
   - `runAuth` throws on missing creds BEFORE calling login → the action handler lets it propagate → non-zero exit. It performs NO fs/DB writes (T: do not auto-persist).
   - The session string is printed to stdout exactly once, surrounded by the store/warn guidance. Do NOT print apiId/apiHash.

Implement the real `LoginFn` (`gramjsLogin`) in the same file, used only by the action (NOT by tests):
```typescript
import { TelegramClient } from 'telegram';
import { StringSession } from 'telegram/sessions/index.js';
import { createInterface } from 'node:readline/promises';

export const gramjsLogin: LoginFn = async ({ apiId, apiHash }) => {
  const rl = createInterface({ input: process.stdin, output: process.stderr });   // prompts on stderr, keep stdout clean
  const client = new TelegramClient(new StringSession(''), apiId, apiHash, { connectionRetries: 5 });
  await client.start({
    phoneNumber: async () => (await rl.question('Phone (+99890...): ')).trim(),
    phoneCode:   async () => (await rl.question('Login code: ')).trim(),
    password:    async () => (await rl.question('2FA password (blank if none): ')).trim(),
    onError:     (e) => { process.stderr.write(String(e) + '\n'); },
  });
  rl.close();
  const session = String(client.session.save());
  await client.disconnect();
  return session;
};
```

Wire the action:
```typescript
export function registerAuth(program: Command): void {
  program.command('auth') /* keep Plan 02 description */

}
```
