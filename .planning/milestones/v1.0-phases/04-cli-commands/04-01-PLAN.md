1. Add interfaces:
```typescript
export interface VacancyFilters {
  source?: string;
  keyword?: string;
  since?: string;   // 'YYYY-MM-DD' inclusive lower bound on created_at
  until?: string;   // 'YYYY-MM-DD' inclusive upper bound on created_at
  limit?: number;   // omit => no LIMIT
}

export interface VacancyRow {
  id: string;
  source_id: string;
  external_id: string | null;
  title: string;
  company: string;
  description: string;
  skills: string[];                // parsed from JSON
  salary_min: number | null;
  salary_max: number | null;
  salary_currency: string | null;
  location: string | null;
  remote_type: string | null;
  apply_contact: string | null;
  lang: string | null;
  date: string;                    // created_at
}
```

2. Implement `queryVacancies(db, filters): VacancyRow[]`:
   - Build a `WHERE` clause incrementally into a `conditions: string[]` and `params: unknown[]` array. EVERY value bound via `?` placeholder — NO template-string interpolation of filter values into SQL.
   - source: `conditions.push('source_id = ?'); params.push(filters.source)`
   - keyword: one condition matching ANY of the four columns:
     ```
     conditions.push('(title LIKE ? OR company LIKE ? OR skills LIKE ? OR description LIKE ?)');
     const kw = '%' + filters.keyword + '%';
     params.push(kw, kw, kw, kw);
     ```
     (skills is stored as a JSON string, so a LIKE substring match on the raw JSON finds the skill token — acceptable for v1 keyword search.)
   - since: `conditions.push('created_at >= ?'); params.push(filters.since)` — for an inclusive upper bound on until, push `until + ' 23:59:59'` so a date-only until covers the whole day: `conditions.push('created_at <= ?'); params.push(filters.until + ' 23:59:59')`.
   - Assemble: `const sql = 'SELECT id, source_id, external_id, title, company, description, skills, salary_min, salary_max, salary_currency, location, remote_type, apply_contact, lang, created_at FROM vacancies' + (conditions.length ? ' WHERE ' + conditions.join(' AND ') : '') + ' ORDER BY created_at DESC' + (limit !== undefined ? ' LIMIT ?' : '');`
   - limit: sanitize like getPendingRawItems — `const lim = filters.limit !== undefined ? Math.max(0, Math.trunc(filters.limit)) : undefined;` and push `lim` to params when defined.
   - Run `db.prepare(sql).all(...params)` and map each raw row to `VacancyRow`, parsing `skills` via `JSON.parse(r.skills ?? '[]')` and setting `date: r.created_at`.
   - Read-only: no transaction needed.
