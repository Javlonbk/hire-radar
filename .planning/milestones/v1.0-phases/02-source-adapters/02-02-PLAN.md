Create `src/adapters/rss.ts` exporting:
```typescript
export interface RssOptions {
  url: string;
  fetchFn?: typeof fetch;   // injectable; default global fetch
}
export function createRssAdapter(opts: RssOptions): SourceAdapter
```

Constructor logic:
1. Parse `new URL(opts.url)`; if `protocol` is not `"http:"` or `"https:"`, throw `new Error("RSS feed URL must be http(s): " + opts.url)` (SSRF scheme guard — T-02-04).
2. Compute `id = "rss:" + contentHash(opts.url).slice(0, 8)`.
3. Hold mutable `etag: string | null` and `lastModified: string | null` captured across fetches (instance-local; persistence of these across runs is out of scope — the 7-day `since` window plus content_hash dedup absorbs overlap).

`fetch(since: Date)`:
1. Build headers: `{ 'User-Agent': 'hire-radar/0.1' }`; if `etag` set add `If-None-Match`; if `lastModified` set add `If-Modified-Since`.
2. `const res = await fetchFn(url, { headers })`. If `res.status === 304` return `[]`.
3. Capture `res.headers.get('etag')` → etag and `res.headers.get('last-modified')` → lastModified.
4. `const buf = Buffer.from(await res.arrayBuffer())`. Detect encoding: regex `/<\?xml[^>]*encoding=["']([^"']+)["']/i` against `buf.toString('latin1', 0, 200)`. If the captured encoding is non-UTF-8 (not /^utf-?8$/i), `xml = iconv.decode(buf, encoding)`; else `xml = buf.toString('utf8')`.
5. `const feed = await new Parser().parseString(xml)`.
6. Map each `item` where `new Date(item.isoDate ?? item.pubDate) >= since`: `nativeId = String(item.guid ?? item.link)`, `rawText = [item.title, item.contentSnippet ?? item.content].filter(Boolean).join("\n")`, `rawJson = item`, `fetchedAt = new Date()`, `contentHash = contentHash(id + ":" + nativeId)`, `sourceId = id`.
7. Return the mapped RawItem[].

Use `import iconv from 'iconv-lite'` and `import Parser from 'rss-parser'`.

Tests inject `fetchFn`: (a) a windows-1251 buffer fixture with one Cyrillic item → assert decoded title contains the expected Cyrillic string (no `Ð`); (b) two items where one predates `since` → assert only the newer is returned; (c) a 304 response → assert `[]` and that the second call sent If-None-Match; (d) `createRssAdapter({ url: 'file:///etc/passwd' })` throws.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.json feed URL → fetch target | Config-supplied URL controls the outbound request destination (SSRF surface) |
| feed response body → parser | Untrusted XML of arbitrary encoding crosses into the parser and into SQLite |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Information Disclosure (SSRF) | createRssAdapter URL handling | mitigate | Reject any URL whose scheme is not http:/https: before fetch — blocks file://, ftp://, gopher:// reaching internal resources via config-supplied URLs |
| T-02-05 | Tampering | XML encoding detection | mitigate | Encoding read from the XML declaration (not blindly trusting Content-Type); transcode via iconv-lite so malformed bytes cannot corrupt stored text (PITFALL-11) |
| T-02-06 | Denial of Service | parseString on hostile feed | accept | rss-parser handles malformed XML by throwing; the orchestrator's per-source try/catch (Plan 03) isolates the failure — no separate size cap in v1 |
</threat_model>
