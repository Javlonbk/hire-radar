Create `src/db/raw-items.ts`:
```typescript
export function persistRawItems(db: Database.Database, items: RawItem[]): number
```
Implementation: build one prepared statement
`INSERT OR IGNORE INTO raw_items (source_id, external_id, raw_text, raw_json, content_hash, fetched_at) VALUES (?,?,?,?,?,?)`.
Wrap the loop in `runInTransaction(db, () => { ... })` (synchronous — no await). For each item: bind `nativeId` to `external_id`, `JSON.stringify(rawJson)` (or null) to `raw_json`, `fetchedAt.toISOString()` to `fetched_at`. Sum `stmt.run(...).changes` and return the total inserted (0 for ignored duplicates). Do NOT set extraction_status (DB default 'pending' satisfies SRCE-05 — raw is persisted before any extraction exists).

Create `src/adapters/hh.ts` exporting:
```typescript
export interface HhOptions {
  area: string;
  text: string;
  perPage: number;
  fetchFn?: typeof fetch;          // default: global fetch — injectable for tests
  sleep?: (ms: number) => Promise<void>;  // default: real setTimeout — injectable
  log?: (msg: string) => void;     // default: console.warn — injectable
}
export function createHhAdapter(opts: HhOptions): SourceAdapter
```

The adapter `id` is the constant `"hh:uz"`.

`fetch(since: Date)`:
1. Loop pages from 0. For each page call `GET https://api.hh.ru/vacancies?area={area}&text={text}&per_page={perPage}&page={page}&date_from={since.toISOString()}` with header `User-Agent: hire-radar/0.1 (+https://github.com/hire-radar)` (PITFALLS Security — anonymous hh requests without UA get 429).
2. Parse JSON. On the first page, capture `found` and `pages`. If `found > 2000`, call `log("hh.uz: query matched " + found + " results but API caps at 2000 — narrow hh.text/hh.area")` (Pitfall 8).
3. For each `item` in `body.items`, build a RawItem: `sourceId: "hh:uz"`, `nativeId: String(item.id)`, `rawText: [item.name, item.employer?.name, item.snippet?.requirement, item.snippet?.responsibility].filter(Boolean).join("\n")`, `rawJson: item`, `fetchedAt: new Date()`, `contentHash: contentHash("hh:uz" + ":" + String(item.id))`.
4. Stop when `page + 1 >= pages` or `page >= 19` (hard 20-page cap). Between pages `await sleep(500)`.
5. Return the accumulated RawItem[].

Default `fetchFn = fetch`, `sleep = (ms) => new Promise(r => setTimeout(r, ms))`, `log = console.warn`.

Tests inject a fake `fetchFn` returning a 2-page fixture (`{found: 3, pages: 2, items: [...]}` then page 2 items), a no-op `sleep`, and a capturing `log`; assert: all items across both pages returned, contentHash is set and stable, `date_from` appears in the requested URL, and the >2000 warning fires for a fixture with `found: 4521`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hire-radar → api.hh.ru | Outbound HTTP to an external REST API; response body is untrusted input parsed into RawItem |
| RawItem → raw_items table | Untrusted external text crosses into local SQLite storage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | hh.ts JSON parsing | mitigate | Treat `body.items` as untrusted: coerce ids with `String(item.id)`, never `eval`; rawText built only from known string fields, no template injection into SQL (parameterized INSERT in raw-items.ts) |
| T-02-02 | Denial of Service | hh.ts pagination loop | mitigate | Hard 20-page / 2000-result cap + 500ms inter-page pace prevents runaway request loops and hh.uz IP ban (PITFALLS Security) |
| T-02-03 | Information Disclosure | raw-items.ts logging | accept | Raw hh.uz payloads are public job postings (no secrets); full payload stored in raw_json is acceptable for this source |
</threat_model>
